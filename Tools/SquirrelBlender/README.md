# Белка: 3D-модель → спрайты

Пайплайн: модель Meshy (FBX) → риг в Blender → анимации (Action) → рендер в прозрачные PNG-кадры → покадровая анимация в Unity.

- `rig.py <fbx> <out_dir>` — импортирует FBX, ставит скелет `SquirrelRig` (30 костей: root, hips, spine, chest, neck, head, уши, четыре лапы по 3 кости, хвост `tail.01`…`tail.10`), считает веса, сохраняет `squirrel_rig.blend`.
- `setup_anim.py <in.blend> <out.blend>` — добавляет камеру `SpriteCam` (ортографическая, вид сбоку, белка смотрит вправо), свет, настройки рендера и пробный Action `idle_test` (дыхание и покачивание хвоста, 60 кадров при 30 fps, цикл 2 с).
- `render_sprites.py` — рендерит Action в кадры и пишет `meta.json` (fps, пикселей на единицу, pivot под лапами):

```
blender -b squirrel_rig.blend -P render_sprites.py -- <action> <out_dir> [size=512] [step=1] [samples=24]
```

Камеру `SpriteCam` между анимациями не двигать: тогда масштаб и pivot у всех клипов совпадают.
Исходники модели и `.blend` в репозиторий не кладём (десятки мегабайт).

## Колыхание прядей

`fur.py <in.blend> <out.blend> [сила=0.05] [debug.png]` добавляет модификатор `FurFlutter` (Displace по крупному шуму) с группой вершин `fur_tips`. Двигаются только тонкие отдельные пряди (кончики хвоста, кисточки ушей, усы, грива): вес растёт от корня пряди к кончику, тело неподвижно. Шум едет по кругу с периодом 60 кадров (объект `FurWind`), поэтому бесшовный цикл получается у анимаций длиной, кратной 60 кадрам. Сила регулируется полем Strength модификатора, 0 выключает эффект. Нужен scipy.

## Базовые анимации

`anims.py <in.blend> <out.blend>` создаёт Action `run` (16 кадров, цикл), `tail_attack_front` и `tail_attack_back` (28 кадров, разовые, боковой взмах: хвост проходит перед белкой или за ней) и `climb` (30 кадров, цикл, стена справа, лапы ставятся на ствол через IK в скрипте). Позы заданы углами в плоскости вида сбоку, поэтому их легко править числами в скрипте или руками в Blender. У каждого Action есть свойство `loop`; `render_sprites.py` по нему решает, рендерить ли последний кадр, и подгоняет период шума прядей под длину цикла. Для `climb` pivot в `meta.json` лежит на стене.

Ещё Action: `tail_spin` (28 кадров, разовый: белка прокручивается вокруг своей оси и бьёт хвостом) и `climb_hug` (30 кадров, цикл: белка обхватывает тонкий ствол). Для `climb_hug` при рендере включается объект `Trunk` с материалом Holdout: он вырезает дальние лапы, которые уходят за ствол. Ствол шириной 0.4 единицы начинается от pivot по X.

Удары в прыжке: `tail_flip_side` (22 кадра: прыжок, переворот через бок, хвост описывает круг) и `tail_flip_front` (24 кадра: сальто вперёд, хвост бьёт сверху при приземлении). У них свойство Action `wide = 1.25`: кадр 640 px вместо 512 при тех же пикселях на единицу, pivot в `meta.json` пересчитан.

Повадки настоящей белки (все циклы): `sit_alert` (90 кадров: столбик, оглядывается рывками), `nibble` (60: сидит и грызёт, лапы у рта), `tail_flag` (60: тревога, серии резких взмахов хвостом), `sniff` (90: обнюхивает землю и поднимает голову). Движения построены по принципу «рывок и замирание» (`track`, `pulse` в скрипте).
